#  TechFlow - Responsive Landing Page

A modern and fully responsive landing page created using **HTML, CSS, and JavaScript**.

##  Project Overview

TechFlow is a modern landing page designed to demonstrate responsive web development skills. The website provides a clean user interface and works smoothly across different screen sizes and devices.

##  Features

- Responsive Navigation Bar
- Mobile Hamburger Menu
- Modern Hero Section
- Services Section
- Features Section
- Call-to-Action Section
- Responsive Footer
- Smooth Scrolling
- Interactive Hover Effects
- Mobile-Friendly Design
- Fully Responsive Layout

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

##  Responsive Design

The website is optimized for different screen sizes:

- 📱 Small Mobile Devices 
- 📱 Mobile Phones 
- 📱 Large Mobile Devices
- 📱 Tablets
- 💻 Laptops 
- 🖥️ Desktop Screens
